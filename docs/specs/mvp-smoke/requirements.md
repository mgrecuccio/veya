# MVP Smoke Requirements

Backlog tickets: 18, 19

## Goal

Keep the MVP release path verifiable with focused automated tests and a final manual smoke checklist.

## Acceptance Criteria

- New service methods have URL, method, and payload assertions.
- Main match flows have success and error-path tests.
- The full MVP loop can be completed on a representative device.
- No client-side WhatsApp URL generation exists.
- Push notification taps refresh backend state.
