# Design System

## Philosophy
- Warm
- Soft
- Rounded
- Mobile-first

## Colors
Primary: #7a63f6
Accent: #f4766a

Gradient:
linear-gradient(180deg, #f8a99a 0%, #f1bfd2 28%, #f6ecf7 62%, #e3d7ff 100%)

## Shapes
- Buttons: pill
- Cards: rounded (~20px)

## UI
- Soft shadows
- Glass effect
- No harsh edges

## Rule
If it feels harsh, it's wrong. If it feels soft, it's right.
