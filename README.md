# Veya Mobile App

A mobile-first social application built with Angular + Ionic + Capacitor.

## Tech Stack
- Angular (standalone)
- Ionic
- SCSS
- Capacitor (Android/iOS)

## Structure
src/app/
- core/
- features/
- shared/

## Run
npm install
ionic serve

## Principles
- UI first, API second
- Reusable components
- Mobile-first UX
