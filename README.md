# Veya

Veya is a mobile application where users maintain a **private list of contacts** and each contact defines availability windows.
When two or more people are free at the same time, the system randomly selects a match and suggests (or initiates) a chat/call.

> “A serendipity engine for existing relationships: I already know people I like, but modern life prevents spontaneous contact.”

## Concept
This app is best understood as a **serendipity engine for existing relationships**.

### What it is
- A way to reconnect with people you already know.
- Availability-aware and spontaneity-driven.
- Built for lightweight, real-world contact.

### What it is not
- Not a dating app.
- Not mainly a friend-discovery app.
- Not just a scheduling app.
